Placement Readiness Evaluator

Problem Statement
Create a Java program that evaluates whether a student is ready to attend a placement drive.

Project Overview
This is a Java application and here we check that particular student is eligible for placement or not.In report we update that what they have to improve.

Student Details
- Student Name
- Academic Percentage
- Attendance Percentage
- Active Backlogs
- Project Completion Status
- Communication Score
- Aptitude Score

Placement Eligibility Criteria
Only if they pass all the criteria, then only they are eligible for placement

- Student Name
- Academic Percentage (>= 60% to pass)
- Attendance Percentage (>= 75% to pass)
- Active Backlogs (0 to pass)
- Project Completed (true/false)
- Communication Score (>= 60 to pass)
- Aptitude Score (>= 60 to pass)

Program Output
- Student Name
- Academic Status
- Attendance Status
- Backlog Status
- Project Status
- Communication Status
- Aptitude Status
- Final Placement Readiness Result
- Areas that require improvement (if any)

Concepts Used

- Primitive Data Types
- String
- Boolean
- Relational Operators
- Logical Operators
- Compound Conditions
- Ternary Operator
